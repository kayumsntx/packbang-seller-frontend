# Packbang Seller Center - Frontend

Packaging supplier marketplace portal for Bangladesh (gift packets, bubble wrap, courier poly, stickers, carton boxes).

## Quick Start

```bash
cd K:\packbang-seller-frontend

# Install dependencies (already included in node_modules)
npm install

# Start Vite Development Server (Port 5173)
npm run dev

# Production Build
npm run build
```

## Backend Connection
The Vite dev server proxies `/api` calls to the backend on `http://localhost:5000`.
Ensure the backend is running in `K:\packbang-seller-backend`.
